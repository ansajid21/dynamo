A command-line deployment starts with a **frontend** (`python -m dynamo.frontend`) that
exposes the OpenAI-compatible HTTP API and one or more **workers**
(`python -m dynamo.<backend>`) that run an inference backend. Workers register with the
frontend when they start, so you can add workers, routing, and serving patterns without
changing the API entry point.

Start with the deployment guide to serve a model with one frontend and one worker. Then
use the other guides to size the deployment or add routing, disaggregation, multiple
nodes, and KV cache offloading.
